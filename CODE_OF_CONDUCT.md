# Code of Conduct

mugilu follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in this repository (issues, pull requests, discussions) and anywhere someone speaks for the project.

## Reporting

Report harassment, abuse or any breach of this code to the project owner:

- Open a [GitHub issue](https://github.com/urbanmorph/mugilu/issues) for anything that can be public.
- For anything private, email [sathya@urbanmorph.com](mailto:sathya@urbanmorph.com) or use GitHub's [private vulnerability reporting](https://github.com/urbanmorph/mugilu/security/advisories/new) form, which only the maintainers see.

We answer every report within 7 days and keep the reporter's identity private. GitHub's own tools also let anyone block a user or report abuse to GitHub.

## Enforcement

The owner reviews each report and acts as the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) set out: a correction, a warning, a temporary ban or a permanent ban.

## Young people

mugilu has no accounts, profiles, messages or user posts, so the site itself offers no way for people to contact each other. Contributors under 18 take part on GitHub under GitHub's own age rules, and reports involving a young person are handled first.
